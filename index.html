DSPIRA

Digital Signal Processing in Radio Astronomy (DSPIRA) is a set of {{ lesson_count }} free lessons on building and using a small horn radio telescope. Teachers developed these lessons through an NSF program at West Virginia University, working with Green Bank Observatory.

You do not need a telescope to begin. The start page has three routes:

  • Try a classroom activity
  • Build a telescope
  • Observe with your telescope

If you are planning a class, see Teach with DSPIRA.
